## Data Visualization Workflow

This notebook pulls housing data from the Census API and turns it into two charts. One chart shows raw housing values, and the other shows percentage-based housing measures.

## Why visualize data? 🤔

Charts make it easier to compare values and notice patterns quickly. They turn a table of numbers into something easier to understand at a glance.

## JupyterLite Notebook Code Cell Sections

### Import Dependencies 🐍

These imports bring in the tools needed to load data, work with tables, and build charts.

```python
import pandas as pd
import matplotlib.pyplot as plt
import json
from js import fetch
```

### Helper Function 🐍

This function fetches JSON data from the Census API and converts it into a Python object.

```python
async def get_json(url):
    resp = await fetch(url)
    txt = await resp.text()
    if not txt:
        raise ValueError("Empty response from Census API")
    return json.loads(txt)
```

### Pull and Prepare Data 🐍

This code requests ACS housing data for Androscoggin County, then separates the values into counts and percentages so they can be charted properly.

```python
url = "https://api.census.gov/data/2024/acs/acs1/profile?get=NAME,DP04_0001E,DP04_0046E,DP04_0047PE,DP04_0058PE,DP04_0132E,DP04_0134E,DP04_0137PE&for=county:001&in=state:23&key=YOUR_KEY"
data = await get_json(url)

df = pd.DataFrame(data[1:], columns=data)
row = df.iloc

count_metrics = {
    "DP04_0001E": "Total housing units",
    "DP04_0046E": "Occupied housing units",
    "DP04_0132E": "Median selected monthly owner costs",
    "DP04_0134E": "Median gross rent",
}

percent_metrics = {
    "DP04_0047PE": "Vacancy rate (%)",
    "DP04_0058PE": "No vehicles available (%)",
    "DP04_0137PE": "Rent over 30% of income (%)",
}

count_df = pd.DataFrame({
    "metric": list(count_metrics.values()),
    "value": [pd.to_numeric(row[c], errors="coerce") for c in count_metrics.keys()]
}).sort_values("value", ascending=False).reset_index(drop=True)

percent_df = pd.DataFrame({
    "metric": list(percent_metrics.values()),
    "value": [pd.to_numeric(row[c], errors="coerce") for c in percent_metrics.keys()]
}).sort_values("value", ascending=False).reset_index(drop=True)
```

### Make the Charts 📊

The first chart shows the housing counts, while the second chart focuses on percentages and uses a 0 to 100 scale.

```python
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 10), layout="constrained")

bars1 = ax1.barh(count_df["metric"], count_df["value"], color="#4C78A8")
ax1.invert_yaxis()
ax1.set_title("Androscoggin County Housing Profile - Counts")
ax1.set_xlabel("Value")
ax1.set_ylabel("")
for bar in bars1:
    width = bar.get_width()
    ax1.text(width, bar.get_y() + bar.get_height() / 2, f"{width:,.0f}",
             va="center", ha="left", fontsize=10)

bars2 = ax2.barh(percent_df["metric"], percent_df["value"], color="#F58518")
ax2.invert_yaxis()
ax2.set_title("Androscoggin County Housing Profile - Percentages")
ax2.set_xlabel("Percent")
ax2.set_ylabel("")
ax2.set_xlim(0, 100)
ax2.set_xticks()[1][2]

for bar in bars2:
    width = bar.get_width()
    ax2.text(width, bar.get_y() + bar.get_height() / 2, f"{width:.1f}%",
             va="center", ha="left", fontsize=10)

plt.show()
```
